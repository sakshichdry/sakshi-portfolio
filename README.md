# Sakshi Choudhary – Personal Portfolio Website

Welcome to my personal portfolio website! I'm Sakshi Choudhary, a startup enthusiast and a student at IIM Bangalore, passionate about entrepreneurship, research, and digital innovation.

## About the Project

This is a responsive personal website built using **HTML and CSS** to showcase my skills, projects, education, and contact details. The goal of this project was to apply web development fundamentals while improving the site’s aesthetics and user experience through CSS enhancements.

---

## Features & Enhancements

### HTML Structure:
- Semantic HTML elements used for clarity and accessibility.
- Sections for About, Skills, Projects, Education, and Contact.

### CSS Styling:
- **Google Fonts** for enhanced readability and modern design.
- **Flexbox navigation bar** for responsive layout and clean structure.
- **Custom color palette** using CSS variables for consistent theming.
- **Card-style project sections** for better content organization.
- **Responsive design** via media queries for mobile-friendliness.
- **Subtle animations** to create smooth visual transitions.
- **Stylized timeline** for education history using borders and spacing.
